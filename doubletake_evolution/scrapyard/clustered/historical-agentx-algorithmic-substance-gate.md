## 1. The mechanism and chronological failure distinction

**ALGO-BASE alleged** harvesting, balancer, gap-filler, frontier and assimilation sources were turned one-for-one into Python files whose implementation was only generic `DOMAIN_FIELDS=()`, `REQUIRED_FIELDS=()`, `THRESHOLDS=()`, `processed=True`, `dispatch/handle_*`, trivial `value/valid` dataclasses or docstrings. Importability, `_main([])==0`, non-None outputs, manifests, type hints, `py_compile`, or a claim of "implemented" did not prove the named algorithm (e.g. adaptive mutation, elite preservation, hybrid retrieval ranking, lineage GC, transition gates). Source/filename/`SOURCE_CAP`/manifest/handler/test identities could also disagree, especially in appended bucket-sink files.

**ALGO-FOLLOW reported partial remediation**, **not independently verified now**: 159 legacy placeholder modules and 180 import-only paired tests removed; 42 underspecified items retained `CONCEPT_ONLY`; seven canonical algorithm families with behavioral tests (adaptive mutation, elite preservation, hybrid ranking, semantic deduplication, ranked selection, lineage GC, ingest gate); stale manifests and generated import clutter reduced; an AST substance gate and typed authoring introduced. **Remaining alleged defect:** `write_code_e2e.author_functional_module()` could still generate `SOURCE_CAP` + `ATOMIC_CAPABILITIES` + `DECISIONS={...:PENDING RECONNAISSANCE}` Python "assimilation packets" with trivial `process()`, `is_valid()` and metadata-only tests. A more elaborate fake packet is still **evidence/specification state, not an algorithm**. Later reports may claim additional fixes; check current DT code before inferring this is live.

## 3. Concrete technical boundary and failure controls

- **Legacy shape not a contract:** `coding_loop._verify_candidate()` must not demand `SOURCE_CAP`, a ceremonial dataclass, `is_valid()`, `_main()`, generic `dispatch/process`; `_smoke_candidate()` must not impose mined-record `DOMAIN_FIELDS/REQUIRED_FIELDS/THRESHOLDS` on schedulers, controllers, rankers, planners or GC. Verify mechanism-specific callable contract, canonical owner, provenance, real behavior, integration reachability and tests.
- **Real test execution before promotion:** `assimilation_governance.promote_candidate()` compiling a candidate and its `test_code` is insufficient. In an isolated bounded rollback transaction, execute candidate-specific behavioral tests and affected canonical tests; failed tests must roll back source, test, manifest and promotion status. Full repository suite is not required per candidate, but tests must actually exercise the mechanism.
- **Fail-closed gate:** historical `_substance_gate_ok()` fallbacks reportedly caught gate exceptions and returned success unless an exact old template matched. Gate import failure, crash, unparseable candidate or ambiguous verdict → **BLOCK**, not success. Check every path (`coding_loop`, `assimilation_governance`, `write_code_e2e`, registry/MCP promotion) and test exception injection.
- **Structural gate, not keyword grep:** combine AST, registry, author decision and test evidence. Reject trivial holders, metadata-only `process`, delegate-only public APIs, renamed handlers, dummy nonempty field tuples, hardcoded success, unresolved packet decisions, docstring-only algorithm, source/manifest/handler mismatch, import-only tests and unbenchmarked performance claims. Legitimate plumbing/fixtures must not be false-rejected; positive and negative controls required.
- **Manifest truth:** `register_mcp_tool()`, package `__init__`, dispatch maps and capability registry may expose only final executable canonical capabilities with real callable, owner, passed substance gate, executed behavioral test, correct manifest signature and provenance. `CONCEPT_ONLY`, `DEFER`, `PENDING RECONNAISSANCE` never register as live tools.
- **No filename identity shortcut:** `write_code_e2e._dedupe()` suffixes (`thing_2.py`) cannot resolve live semantic collisions; use compare/merge/adapt/already-exists/owner defer. A universal `collective_synthesized` fallback is not a substitute for canonical owner. Numeric suffixing is acceptable only for temporary non-source artifact IDs.
- **Generated state:** stale ignored coding buckets, assimilation staging, indexes and write-code/integration ledgers can falsely imply `already_done`. Preserve provenance, distinguish genuine source from fake staged artifacts and follow owner-approved retention before retiring any state; do not use this historical prompt as authorization to delete protected DT history.
