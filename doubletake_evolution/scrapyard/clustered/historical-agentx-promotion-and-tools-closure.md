- **Orphan artifact record:** classify `STALE_METADATA`, `DELETED_ARTIFACT_REFERENCE`, `MOVED_ARTIFACT_REFERENCE`, `LEGITIMATE_EXTERNAL_ARTIFACT`, `MISSING_REQUIRED_ARTIFACT`, `CORRUPT_RECORD`. Remove stale/intentionally deleted references (preserving provenance), repoint moved records, retain legitimate external with validation, restore only genuinely required real artifacts, repair corrupt records fail-closed.
- **Orphan module record:** distinguish intentionally deleted, moved/renamed, merged, dynamic loaded, genuinely missing or stale metadata. Delete stale record; repoint moved/merged identity to canonical owner; keep real dynamic consumer with proof; never synthesize placeholders to satisfy inventory.

- **Empty initializers:** preserve when required for real package/import, discovery, loader, test isolation or regular-package tooling; otherwise delete after checking namespace-package semantics and callers. Remove empty directories only after verified non-use.
- **Dangling references:** check manifests, registries, Makefiles, package initializers, import/capability maps, proof inventories, machine-consumed docs, tests and generated indexes.
- **Historical test blockers:** missing helper or patch import may mean moved legitimate code, obsolete test, or required implementation. Repair actual imports/real code or retire stale tests, **not** dummy modules. Resolve duplicate pytest module name via correct rename/package structure/removal; do not disable discovery globally.
