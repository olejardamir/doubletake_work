## Mechanism and authority boundary

Routine closed-choice Borg control from machine-readable facts, policy and current state should produce the **same authoritative route/verdict/action with provider present or absent**. This includes candidate selection, completion, allocation, safety/repair, capability routing, assimilation admission and automatic code mutation. Open-ended research, coding, diagnosis and semantic synthesis can use an LLM **only via an explicit governed System-Two request**; model output never itself grants mutation or bypasses validation. Semantic retrieval can supply candidate evidence without determining the final authoritative route. A model may provide non-authoritative explanation without changing a routine decision. The test is *what the output controls and who calls it*, not the mere presence of `provider` or `llm_` in a filename.

**Classification per reachable production caller:** `ROUTINE_CONTROL_FLOW` (bounded machine-state choice), `GENUINE_SYSTEM_TWO` (explicit open-ended work), `DIAGNOSTIC_NON_AUTHORITATIVE` (cannot alter action), `DEAD_UNREACHABLE` (no supported live caller/import/contract), or `UNKNOWN` (further trace required). Trace caller → provider origin → controlled state/effect → current deterministic evidence → owner/authorization. No final closure while a reachable decision remains UNKNOWN. A default `provider=None` does not establish that production never supplies a provider.
