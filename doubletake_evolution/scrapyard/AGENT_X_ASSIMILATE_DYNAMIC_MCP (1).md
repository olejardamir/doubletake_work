## Distinct transferable mechanism

Unify MCP, native tools, skills, services and callable specialists under the **existing** DT capability catalog/resolver, rather than introducing an MCP-only router. Provider adapter → normalized descriptor → structural and **hard authority** eligibility → lexical/semantic candidate retrieval → deterministic fusion → contextual rerank → bounded K/token/schema projection → exact current-schema/authority/provider revalidation → governed invocation → telemetry. Ranking must never grant authority. Only currently projected canonical identities may execute; guessed names fail closed.

Descriptor: stable provider-qualified identity, aliases, schema hash/revision, provider revision/health, required permissions and approval, task/worker compatibility, cost/latency, availability and indexed metadata. Refresh must detect add/remove/schema change and invalidate affected indexes and caches. Cached authorization cannot outlive policy changes. Compact metadata may be indexed, but execution must use the exact current schema. Independent lexical/semantic pools with deterministic deduplication; lexical fallback on semantic outage; bounded cold-start feedback. Preserve existing DT owners and reject redundant registries, vector databases or dependencies.

## Falsifiable acceptance / negative controls

- Mixed MCP/native mock providers resolve through one authorized path, including same-named tools with distinct provider IDs; stable deduplication and deterministic selection.
- Permission revoked after projection, provider removed, schema changed, stale cache, malicious provider metadata, unprojected/guessed ID, malformed schema or arguments: **zero unauthorized exposure or execution**; explicit safe rejection. No-candidate path fails closed. Semantic retrieval outage retains authorized lexical fallback.
- Synthetic 100/1,000/5,000-capability catalogs where feasible: record index/retrieval/rerank latency, top-K hit quality, prompt/schema bytes, final K and budgets; compare with existing DT baseline. Context cost should not scale with full catalog on affected paths; do not claim performance without measured data.
- Prove current production owner mapping, actual commits, unit/integration/security tests and full-import/host results; test exact committed revision, not an isolated uncommitted substitute. Preserve negative evidence and regressions.
