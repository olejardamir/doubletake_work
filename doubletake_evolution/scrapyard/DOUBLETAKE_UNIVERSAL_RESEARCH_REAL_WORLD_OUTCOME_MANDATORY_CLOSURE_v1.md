## 2. Acceptance question: natural URL-free user query → independently witnessed real outcome

Historical exemplar: *Find affordable monthly parking near the Bank of Canada office in downtown Ottawa; compare currently published options and identify what vacancy information is actually verified.* The geographic anchor must be resolved from a trustworthy source at runtime; this is a test input, **not** a hardcoded address or permanent preference.

A **real completed search** requires all seven linked facts, bound to the same run ID and retained source revision:

1. Ordinary Chat UI recognizes research intent and applies **existing** permissions; user supplies **no URLs** and no special activation command.
2. A configured, legitimate **non-fixture discovery provider** independently yields candidate source references. Empty candidates, remembered links and invented results do not count.
3. A governed authorized broker fetches actual external non-loopback content; receipt includes provider, canonical URL/identifier, response status, timestamp, content digest and authorization. Test server/mock/loopback or model assertion does not count.
4. Evidence-backed extraction/normalization/fusion links each material parking fact to an acquired source anchor, reconciles freshness/conflicts and marks unknowns explicitly.
5. The **real browser Chat UI** shows a useful source-linked comparison, or an honestly evidenced negative/limited result. UI-only activity, `CONSENT_REQUIRED` or an ungrounded answer is not delivery.
6. A **separate verifier** checks actual source receipts, claim links, browser observation, allowed effects and evidence integrity rather than relying on a self-certified LLM summary.
7. Security, no-web, access-control, stale-source, corruption and regression negatives pass at the same retained revision.

**Truthfulness:** aim for three genuinely distinct contactable options if published; fewer is fine when supported. A parking listing does **not** establish a vacant space. Preserve rate currency and period (daily/hourly/monthly), taxes/fees, restrictions, contact/booking link only if published, checked-at vs effective date, geographic evidence and route/walking estimate only if independently measured. Never silently convert daily to monthly, infer current inventory, invent prices, double-count duplicates or rank incomparable rates. Unknown availability is **unknown**, not confirmed. If no usable option exists, a genuine completed live search may be valid without claiming a space was found.

## 5. Outcome classification and reproducibility boundaries

- `ENGINEERING_READY_LIVE_PENDING`: code/fixture evidence only; **not done**.
- `BLOCKED_REAL_WORLD_OUTCOME`: attempted but permission/provider/discovery/acquisition/evidence/UI blocker remains; **not done**, exact cause and lawful next step recorded.
- `LIVE_SEARCH_VERIFIED`: independently witnessed real provider + useful truthful browser result + all required gates; **search completed**.
- `LIVE_SEARCH_COMPLETED_NO_CONFIRMED_SPACE`: verified search subtype; **no vacancy claimed**.
- `LIVE_SEARCH_COMPLETED_ACTIONABLE_OPTIONS`: genuinely sourced contactable options, vacancy may remain unknown.
- `SPACE_AVAILABILITY_CONFIRMED`: only if trusted contemporaneous source actually confirms a space.

A live record certifies **what happened at its timestamp**, not permanent current price or inventory. No false success from HTTP 200, a synthetic provider, a populated activity row, a passing fixture or an `ENGINEERING_COMPLETE_LIVE_UNPROVEN` label. If authorization or internet is unavailable, record precise `BLOCKED`; do not promise a vacancy or force network access.

**Minimum reproducibility record:** exact DT source SHA, actual Chat/browser run ID, original query, permission/grant decision, discovered candidate set, non-loopback acquired-source receipts/digests/timestamps, source-to-claim links, displayed answer evidence, verifier version/result, corruption and no-web controls, regression command/exit/counts, closure verdict and responsible owner. Reproduce on an authorized current checkout; original historical scripts and old local host path are **not instructions**. Preserve other agents' changes, single-main/no-force-push and protected retained history.
