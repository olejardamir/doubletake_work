## Unique transferable mechanism
A cheap, *bounded* semantic decision layer may sit **below deterministic governance and above strong LLM escalation**. Sequence: hard deterministic invariant → cheap algorithmic probe → typed Von choice/score/no-uncertainty decision (historical primitive label `noul`, verify actual catalog semantics) → registered action validated by governance → authorized execution/evidence → revised state. Strong LLM/OpenCode handles novel coding/research; the small model never grants authority, executes shell commands or invents actions. Prefer existing DT runtime/controller, workers, policy, evidence, session and collective stores; no parallel controller or database. This proposal is conditional on an actual measured DT gap and available authorized resources.

- **Catalog and state:** validate catalog version/digest, unique decision IDs, primitive types, action references and invariants. Compile deterministic, size-bounded, secret-redacted, decision-specific state with objective, evidence, revision, constraints, candidate choices and resource status; never feed whole Borg documents at runtime. Catalog historically claimed 85 decisions, not verified.
- **Adapter and dispatch:** loopback-only, bounded timeout/retry, health probe, schema/response validation, latency and backend provenance. Only registered semantic actions map to existing DT capabilities. Unknown action, malformed result, stale revision or failed authorization **must not dispatch**. Record allowed candidates, state/catalog digests, confidence, decision, override, action and outcome without secrets.
- **Nanoprobe separation:** typed read-only discovery/evidence/topology/lineage/behavior probes cannot self-promote to mutation. Any repair/adaptation requires separate scoped authorization, budget, lineage, stale-target checks and rollback evidence.
- **Reliability and modes:** DISABLED, ADVISORY (initial default), and governed AUTO_ELIGIBLE; maintain per-decision `UNTESTED/ADVISORY/AUTO_ELIGIBLE/DISABLED` evidence, not a global accuracy switch. Low confidence, ambiguity, offline service, version mismatch or repeated oscillation → safe defer or governed System-Two escalation, never fabricated success or unrestricted fallback. Decision must be bound to current state revision.
- **Efficiency hypothesis:** use deterministic/algorithmic decisions before local semantic judgment, and remote reasoning only when necessary. Requires measured latency, cost, error, coverage and escalation rates; no claimed improvement.
