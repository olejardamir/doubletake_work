## Falsifiable H-019: compression can be tested for semantic and behavioral fidelity

For a preselected, rights-cleared, public-safe original→condensed pair, a downstream reader using **only the condensed note** should retain all preregistered safety/authority boundaries, source-versus-inference labels, version-specific exceptions and decision-critical negatives from the original, and should choose the same justified disposition on matched held-out questions. An original note, shorter note and verified Git SHA **alone** do not prove this.

**OUTWARD — freeze before testing:** Start with the *already public-safe* original and condensed IS-018 versions; do not expose any protected/private patch, historical owner data or unreleased source. Independently extract 8–12 source-grounded probes before looking at the condensed note: bibliographic provenance, exact scope, one positive and one negative condition, one conditional permission boundary, one missing prerequisite, one version/identity caveat and a correct defer/reject case. Add a separately authored tiny synthetic note with a known intentionally lossy summary as a positive failure control, plus an unchanged note as a no-change control. Record both blob SHAs, probes, gold answers, scorer and resource budget.

**INWARD — authorized, disposable comparison:** Under a fixed reader/model/evaluator and matched context budget, blind the order of (A) original-only, (B) condensed-only, (C) condensed plus *explicitly permitted* original-source lookup, (D) condensed with one critical caveat removed or reversed (synthetic corruption), and (E) irrelevant length-matched note. Score factual retention and *disposition/action selection*, not textual similarity or token savings alone. Require citations to the actual supplied blob. If the model can fetch other context, isolate or log that access; otherwise A/B attribution is invalid. Do not install an agent, change any canonical file, or access private DT. Keep full test answers and disagreements as local authorized research output, not public sensitive logs.

**GROUND — what would falsify the hypothesis:** On the frozen public-safe pair, any independently confirmed false authorization, erased fail-closed condition, misattributed source claim, or wrong disposition in B relative to A is a **compression-fidelity failure candidate** requiring human source check. If B retains all frozen critical boundaries and dispositions, report `NO_OBSERVED_LOSS_ON_TESTED_PROBES` (not universal safety).
