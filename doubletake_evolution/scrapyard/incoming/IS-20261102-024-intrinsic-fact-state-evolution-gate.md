## Primary evidence and precise limits

Toma, de Kernier, Ply & Matei, *Beyond Downstream QA: Rethinking How We Evaluate Agent Memory*, arXiv:2610.22209v1 (2026-10-15), https://arxiv.org/html/2610.22209v1 §§3,5–7, Appendix A. Authors propose FEB-30: **30 synthetic fact-evolution trajectories**, six diagnostic categories (compensation, retrieval, classification, synthesis, temporal, multi-author), three difficulty levels, expected atomic fact states and create/update/reinforce/supersede labels. Compare intrinsic fact-store coverage and transition correctness against extrinsic QA. A correct answer can conceal faulty storage; an incorrect answer can reflect retrieval failure despite correct storage.

**Author-reported, not replicated or DT-specific:** one representative memory system, 11 runs: mean absolute intrinsic/extrinsic divergence **0.168±0.025**; **43.6%** of trajectories exceed an explicitly chosen 0.15 divergence threshold; operation-label accuracy **20.1±2.7%**. Signed intrinsic-minus-extrinsic mean **+0.118**, distinct from absolute divergence. C1's category aggregate actually has *better* intrinsic than extrinsic performance; do not assert compensation is its observed dominant cause. Some category/configuration robustness checks share the same architecture, not independent broad transfer.

**Important method ambiguity:** §5.1 says “after processing all artifacts” it compares store `F` with expected `C_i` at each state, while the text and figure describe per-ingestion evaluation. Confirm actual snapshot/replay semantics before adopting per-state benchmark scores; do not silently treat final-store comparison as a proven historical state oracle. Embedding cutoff >0.8 + LLM entailment judges add measurement error. Synthetic documents, only 30 trajectories, factual (not episodic/procedural) scope, and single evaluated system limit generality. The paper claims code/data release, but https://github.com/amazon-science/feb-30-benchmark returned GitHub **404 on 2026-11-02**; reproducibility and code license remain UNKNOWN. No code/data imported or executed. arXiv page shows its perpetual non-exclusive license; do not infer third-party code redistribution permission.
