## Architecture and authority

Full DoubleTake remains intact. A separately built, physically restricted enterprise artifact reuses the governed core (capability selection, planning/meta reasoning, context, evidence/verification, bounded local state, workspace security), without a parallel control plane or enterprise fork of business logic. A single **provider-neutral CodingAgent** contract separates orchestration from adapters; use an existing canonical abstraction if present. Normalized concepts: session ref, task, status, event, changeset, command/test outcome, final result, adapter. Operations: start/resume, task/repair continuation, status, cancel, event stream, changed files, command/test metadata, final outcome. No OpenCode REST, Codex SDK, OpenAI/Claude chat, MCP, AHP or terminal/shell scraping assumed in the contract; typed fields must have consumers.

A deterministic local MockCodingAgent proves decoupling without credentials, network, daemon, model or external service. Script success, failure, repair, cancel, timeout/stall, file changes, test outcomes, invalid backend results, unavailable backend, and durable resume if supported. Mock must not invent success or contain orchestration intelligence. A future Copilot adapter, if approved, belongs *below* the canonical contract.

## Packaging and explicit exclusions

Build the enterprise artifact from a **closed allowlist**, not full DT plus `ENTERPRISE=true`. Include only necessary governed core, policy/routing, task supervision, context, workspace/secret boundaries, evidence and verification, local run state, canonical contract, mock, security profile, manifest and tests. No wholesale directory inclusion. New files in full DT must not auto-enter enterprise. Keep normal DT providers, MCP, research/self-evolution and UI working in the full distribution.

Exclude from the enterprise *actual package, imports, dependencies and reachable execution paths*: Codex, OpenCode, Claude, generic HTTP LLM/API providers, remote embeddings, VPN/NetworkManager/public-IP manipulation, remote corpus/harvest/assimilation, arbitrary MCP, web/browser, autonomous self-evolution/self-update/code promotion, unnecessary detached daemon/schedulers, unrestricted shell/PowerShell/CMD/package installation/git push. Exclude development/research corpora, donor materials, unsafe fixtures and historical prompts unless genuinely required at runtime. Provider-only dependencies (e.g. `openai-codex`, `@opencode-ai/plugin`) must not be required by the enterprise distribution. Historical source paths and dependency files mentioned in the original are inspection leads, NOT verified current paths.

Network policy distinguishes `EXTERNAL_NETWORK_EGRESS=DENY` from `LOCAL_APPROVED_AGENT_IPC=NOT_YET_IMPLEMENTED`; no broad network allowance in anticipation of AHP. Unknown provider/tool/network/process requests fail closed. No external-model credentials are owned by enterprise DT.

## Isolation and privacy boundaries

Default read scope: authorized active workspace and explicitly bounded runtime state; write scope: runtime-state root; direct source write not required in pre-Copilot v1. Deny outside-workspace reads/writes. Test traversal, absolute path escape, prefix collision, mixed separators, drive-letter casing, UNC, case-insensitive collisions and junction/reparse/symlink escape where testable. Do not claim live Windows PASS from Linux-only tests.

No arbitrary command execution is needed for v1: command-like results come from mock events, not shell wrappers. Corporate-safe logging may retain run id, time, operation, backend, digest/length, status, policy-approved changed filenames, verification, duration and reason code; secrets and raw prompt/response/source transcripts must not persist. An environment variable must not enable full logging. Memory: run-scoped permitted; bounded same-project optional under policy; cross-project, global/personal, remote sync and restricted/secret persistence denied. No remote embedding for memory.
