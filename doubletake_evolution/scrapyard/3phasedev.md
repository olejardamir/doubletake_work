## Universal governed OUTWARD → INWARD → GROUND contract

1. **Outward:** Retrieve original paper, exact revision, code commit, license, checksum, dependencies and any independent replication; record negative findings. Reproduce a minimal safe original experiment only if permitted. Research links alone are not proof.
2. **Inward:** Translate one falsifiable mechanism into existing DT owners; compare existing equivalents, avoid parallel controller/registry/memory and wholesale code import. Distinguish source fact, hypothesis and permission; no L0/L1 bypass or automatic promotion.
3. **Ground:** Freeze baseline, use held-out tasks and matched compute/evaluation budgets, evaluate failure/forgetting/cost/security, retain independent evaluator and rollback. Reject or defer without measured advantage. Test actual caller path and later reuse; paper success or isolated mock test is not DT Ground.
