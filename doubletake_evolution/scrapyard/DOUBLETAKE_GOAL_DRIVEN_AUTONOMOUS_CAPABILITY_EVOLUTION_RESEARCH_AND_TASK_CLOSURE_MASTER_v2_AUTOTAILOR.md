## AutoTailor research hypothesis (source claims separated from DT evidence)

Historical cited paper: Cao, Szekeres & Faisal, *AutoTailor: Automatic, User-Aligned Capability Selection and Adaptation for Web Agents*, arXiv:2609.13548 (Sep 2026), https://arxiv.org/abs/2609.13548 ; candidate PDF https://arxiv.org/pdf/2609.13548 . Historical text attributes to authors 106 WebArena Postmill tasks, API inventory 1,283→87, dynamic selection 33, 90.6% correctness with ReAct fallback, 57.8% request-token reduction and 29.4% latency reduction. **Primary arXiv abstract independently checked on 2026-11-02:** title/authors/date (2026-09-11), 106 tasks, 1,283→87→33, 90.6% correctness vs ReAct-only 87.5%, 57.8% token and 29.4% latency reductions agree with the abstract. The abstract also reports 60.1% correctness and 94.9% token reduction without ReAct; these distinct comparison arms must not be conflated. No paper experiment or DT result independently replicated; not DT thresholds.** Verify actual manuscript/version, methodology, paper license, author links and official code (if any) before method attribution; `NO_VERIFIED_OFFICIAL_REPO` and `PAPER_FULL_TEXT_UNAVAILABLE` are valid. No third-party code copied.

- **A Trajectory-derived reusable tools:** only successful authorized audited workflows; parameterize schemas, pre/postconditions and semantic locators, strip secrets/PII/cookies/irreversible actions; test changed sites/DOM, injection, retries, permissions, cost. A recording alone is not a capability.
- **B Quality/granularity:** evaluate typed interface and actual behavior, necessity, generality, least privilege, correctness, reliability, maintenance, token/latency cost and redundancy. Preserve rarely invoked safety, recovery and accessibility tools.
- **C Usage likelihood:** condition compact active selection on goal, stage, measured workload, resources and grants; master registry remains recoverable. Distinguish `INACTIVE`, `ARCHIVED`, `UNAVAILABLE`, `REMOVED`.
- **D Dynamic reselection:** diagnose wrong tool vs poor source vs transient failure vs denial vs genuine gap; retry existing lawful capabilities first, then governed child; replan original parent with anti-oscillation, audit and reversible pruning.
- **E Fallback:** existing permitted browser/API/reasoning path rather than new ReAct model or manager; inherit original consent and input validation.

For each mechanism record primary-paper section, current DT analog/owner, missing delta, permission, cost, risks, baseline/counterfactual, test/ablation, rollback and decision `ADOPT / ALREADY_COVERED / REJECT / BLOCKED / GAIN_UNPROVEN`. Paper citation or tool count is not evidence of adoption. No mechanism is mandatory to promote when tests show no gain.
