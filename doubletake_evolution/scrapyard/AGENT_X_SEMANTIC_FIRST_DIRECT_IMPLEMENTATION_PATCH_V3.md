## Five distinct historical integration failures and necessary mechanisms

1. **False production end-to-end proof:** `tests/unified_runtime/test_semantic_unified_runtime_e2e.py` replaced `build_unified_runtime_semantic_service` with a spy factory calling `make_service`. A production coordinator calling a fake builder is not evidence that normal production binding works. Required test must exercise the real builders and governance; only the external embedding network/transport leaf may be stubbed deterministically. Non-replacing `wraps=real_function` instrumentation is acceptable. Helpers are part of the prohibited substitution call graph.
2. **Missing default authority:** `tools/agentx_evolve/unified_runtime/api.py` had `_semantic_authority_provider=None`; a test-installed `set_semantic_authority_provider` did not prove normal bootstrap. The default resolver must obtain existing accepted typed objects from canonical bootstrap/config owners; separate test override from production default, and restore production resolution when cleared. Explicit unavailable is valid only after a real resolver checks configuration. No authority from request preferences, environment strings, invented revisions/dimensions, fake `DataScope`, path hashes or `_test_data_scope/_test_policy/_test_calibration` metadata.
3. **Duplicate rollout algorithm:** coordinator `_resolve_semantic_mode_for_intent` independently read `AGENTX_UNIFIED_RUNTIME_SEMANTIC_ROLLOUT`, caught errors and could choose `disabled`. `semantic_binding.py` must be the single authority/rollout resolver. Calibrated missing/invalid authority or binding failure is **BLOCKED**, never silent legacy fallback; shadow may degrade advisorially; disabled has no semantic obligation. No `AGENTX_SELF_UPGRADE_SEMANTIC_ROLLOUT` leakage into Unified Runtime.
4. **Post-commit semantic inconsistency hidden:** after governed mutation, `_perform_incremental_semantic_update` could raise/return false and a broad `except Exception: pass` could still lead to `WORK_UNIT_COMPLETED`. In calibrated mode, preserve truthful committed mutation, persist changed paths/working-set/operation/mode/error and `BLOCKED` or `RECONCILIATION_REQUIRED`; no false `SEMANTIC_INDEX_UPDATED`, `WORK_UNIT_COMPLETED` or `COMPLETED`. In shadow mode emit explicit advisory fallback; disabled mode follows legacy path.
5. **Misclassified proof fabric:** `tools/agentx_evolve/semantic_execution/prove_fabric.py` may use `FakeEmbeddingProvider`/`make_service` in isolated component tests, **not** the Unified Runtime production integration gate. A deterministic transport proves `LOCAL_INTEGRITY`, never `REAL_PROVIDER_QUALIFICATION`.
