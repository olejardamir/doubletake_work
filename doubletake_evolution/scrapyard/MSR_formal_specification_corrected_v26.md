## 1. Problem Formulation

Let \(n\ge 1\) be the bit-length parameter and define

\[
N=2^n,
\qquad
\mathcal{X}=\{0,1\}^n.
\]

The target application is the concrete instance \(n=256\), for which
\(N=2^{256}\). All asymptotic statements below refer to a sequence of
instances indexed by \(n\to\infty\). Thus, objects such as
\(\mathcal{X}\), \(f\), \(A\), \(B\), \(C\), and \(D\) are understood
instance-by-instance, even when the subscript \(n\) is suppressed for
readability.

Fix the big-endian binary-coordinate bijection

\[
\phi:\mathcal{X}\to\mathbb{Z}_N,
\qquad
\phi(x_1x_2\cdots x_n)
=
\sum_{j=1}^{n}x_j2^{n-j},
\]

where each \(x_j\in\{0,1\}\). This removes any ambiguity about bit order.
Define modular addition and subtraction on \(\mathcal{X}\) by

\[
x\oplus k
=
\phi^{-1}\!\left(\phi(x)+k \pmod N\right),
\]

\[
x\ominus k
=
\phi^{-1}\!\left(\phi(x)-k \pmod N\right),
\qquad
x\in\mathcal{X},\ k\in\mathbb{Z}.
\]

Let

\[
f:\mathcal{X}\to\mathcal{X}
\]

be a deterministic permutation. For the generic complexity analysis, \(f\) is modeled as an ideal random permutation exposed only through a forward oracle.

A conventional block cipher under a known key is not an appropriate hardness
example, because its decryption algorithm normally provides efficient
evaluation of \(f^{-1}\).


In every case considered below, \(f\) is bijective.

Let \(A,C\in\mathcal{X}\) be unknown latent states, and let \(B,D\in\mathcal{X}\) be observed states satisfying

\[
B=f(A),
\qquad
D=f(C).
\]

Define the unique directed displacement \(\Delta\) from \(A\) to \(C\) by

\[
C=A\oplus\Delta,
\qquad
\Delta\in\{0,1,\ldots,N-1\}.
\]

Equivalently,

\[
\Delta
=
\bigl(\phi(C)-\phi(A)\bigr)\bmod N,
\]

where the residue is represented by its canonical integer in
\(\{0,\ldots,N-1\}\).

Because modular subtraction assigns exactly one such \(\Delta\) to every ordered pair \((A,C)\), this equation is a definition rather than an additional restriction on the pair. The relation becomes a substantive promise only if extra information is supplied, such as a restricted candidate set, a prior distribution, or a bound on \(\Delta\). No such extra promise is assumed in the generic analysis below.

### Core Objective

Given \(B\), \(D\), and classical forward-oracle access to \(f\), characterize the latent directed displacement \(\Delta\) and determine the generic computational cost of recovering it.

The MSR construction is a mathematical reframing of this problem. It does not, by itself, provide an inversion shortcut.

### 1.1 Keyed-Family Qualification

An unknown-key block cipher requires separate treatment. For each instance
size \(n\), let \(\kappa=\kappa(n)\in\mathbb{N}\) be the positive integer
key length and suppose that
the previously defined permutation is the instantiated member \(f=f_K\) of a
publicly known keyed family of permutations

\[
\mathcal{F}_n
=
\left\{
f_K^{(n)}\in\operatorname{Sym}(\mathcal{X})
\ \middle|\
K\in\{0,1\}^{\kappa(n)}
\right\},
\]

where \(\operatorname{Sym}(\mathcal{X})\) denotes the set of all bijections
from \(\mathcal{X}\) to itself.

To reduce notation, the superscript \((n)\) and the argument \(n\) on
\(\kappa\) are suppressed below when no ambiguity results.

The public keyed-family description is additional information that is absent
from the ideal-permutation oracle model. Let

\[
t=t(n)\in\{1,\ldots,N\}.
\]

By making \(t\) forward queries at pairwise distinct inputs
\(x_1,\ldots,x_t\), an evaluator can obtain the verification set

\[
S=\{(x_i,f_K(x_i)):1\le i\le t\}.
\]

Distinctness may be assumed without loss for this straightforward strategy:
repeating an input supplies no new verification constraint and only increases
the work count.

Define the surviving-key set

\[
\mathcal{K}_S
=
\left\{
K'\in\{0,1\}^{\kappa}:
f_{K'}(x_i)=f_K(x_i)\ \text{for every }i
\right\}.
\]

Because the observed verification pairs were generated by \(f_K\), the true
key satisfies \(K\in\mathcal{K}_S\). Hence
\(\mathcal{K}_S\ne\varnothing\).

Assume additionally that, once a candidate key \(K'\) is known, both
\(f_{K'}\) and \(f_{K'}^{-1}\) can be evaluated efficiently. This is true for
an ordinary block-cipher family with public encryption and decryption
algorithms, but it is not implied merely by saying that
\(\{f_{K'}\}\) is a family of permutations.

For each surviving key, define its candidate displacement by

\[
\Delta_{K'}
=
\left(
\phi(f_{K'}^{-1}(D))
-
\phi(f_{K'}^{-1}(B))
\right)\bmod N.
\]

Key enumeration yields an exact route to the desired displacement under the
following **displacement-identifiability condition**:

\[
\left|\{\Delta_{K'}:K'\in\mathcal{K}_S\}\right|=1.
\]

A unique surviving key is sufficient, as is the stronger condition that all
surviving keys induce the same two preimages. Neither condition is necessary:
different surviving keys may induce different preimages while still yielding
the same displacement.

The complexity statement below treats displacement identifiability as an
external promise about \(S\) and the keyed family. Under that promise, finding and selecting any one surviving key is sufficient.

If the promise is not supplied and must instead be **certified**, finding one
surviving key is not enough. A direct classical certification procedure scans
the entire candidate-key space to ensure that no unexamined key survives with
a conflicting displacement. In the straightforward implementation, this
requires

\[
O(t2^\kappa)
\]

forward family evaluations to classify all candidate keys, followed by
\(O(r)\) pairs of inverse evaluations for the \(r=|\mathcal{K}_S|\)
surviving keys. If an earlier promised-case search stopped after finding its
first survivor, certification requires completing the remaining key-space
scan; the extra work is not bounded merely by \(r\).

If the displacement-identifiability condition fails, selecting an arbitrary
key consistent with finitely many samples need not determine the operative
permutation or the desired \(\Delta\).

When displacement identifiability is promised and one public evaluation of
\(f_{K'}\) or \(f_{K'}^{-1}\) is treated as unit-cost computation, a
worst-case exhaustive search for one surviving key uses \(t\) queries to the
instantiated target oracle, at most \(O(t2^\kappa)\) offline forward
evaluations, and only \(O(1)\) additional inverse evaluations after a
survivor has been selected. Thus, \(O(t2^\kappa)\) is a computational-work
upper bound for this particular implementation; it is **not** an
\(O(2^\kappa)\) query count to the target oracle \(f_K\), nor a lower bound
against family-specific algorithms. Without the promise, the full
certification cost described above must be included.

The ideal-permutation analysis counts calls to an abstract target oracle,
whereas keyed-family enumeration counts local evaluations of a public
algorithm. These are different resources. They may be compared only after a
cost normalization is specified.

Under the artificial normalization that one local forward-family evaluation
and one ideal-permutation oracle query each have unit cost, the two displayed
operation counts satisfy

\[
t(n)2^{\kappa(n)}=o(2^n)
\]

exactly when

\[
n-\kappa(n)-\log_2 t(n)\longrightarrow+\infty.
\]

Without that normalization, this relation compares only the numerical counts,
not running time or physical cost. It is also not a necessary condition for
every possible algorithm on the keyed family. Early stopping, multiple
surviving keys, differing implementation costs, or family-specific
cryptanalysis may change the actual work.

Therefore, the \(\Theta(2^n)\) classical and
\(\Theta(2^{n/2})\) quantum bounds proved below are ideal-permutation
black-box query bounds. They do not automatically apply to a succinct keyed
family merely because each \(f_K\) is bijective. A block cipher is relevant
only after its key length, public algorithmic structure, displacement-identifiability and efficient-inversion assumptions, permitted
queries, and computational cost model are stated
separately.

## 2. The Induced Permutation Graph

Define the latent successor permutation associated with the coordinate map
\(\phi\) by

\[
s_\phi:\mathcal{X}\to\mathcal{X},
\qquad
s_\phi(x)=x\oplus 1.
\]

Because addition by one modulo \(N\) visits every element exactly once before
returning to its starting point, \(s_\phi\) is a single cycle of length
\(N\).

Define the corresponding observation-space transition permutation by
conjugation:

\[
g_{f,\phi}
=
f\circ s_\phi\circ f^{-1}.
\]

Thus,

\[
g_{f,\phi}(y)
=
f\!\left(f^{-1}(y)\oplus 1\right).
\]

Since conjugate permutations have the same cycle structure,
\(g_{f,\phi}\) is also a single directed cycle of length \(N\).

Define the induced directed graph explicitly by

\[
G_{f,\phi}=(V,E),
\qquad
V=\mathcal{X},
\qquad
E=\{(y,g_{f,\phi}(y)):y\in\mathcal{X}\}.
\]

The notation includes \(\phi\) because the successor map
\(s_\phi(x)=x\oplus1\), and therefore
\(g_{f,\phi}=f\circ s_\phi\circ f^{-1}\), depends on the chosen arithmetic
coordinate map. Every vertex has indegree \(1\) and
outdegree \(1\), and the conjugacy argument shows that
\(G_{f,\phi}\) is a single directed \(N\)-cycle. In particular, it is
strongly connected.

This does **not** imply that \(f\) itself is a single-cycle permutation.
The single-cycle property belongs to \(s_\phi\) and to its conjugate
\(g_{f,\phi}\).

The construction also depends on the chosen coordinate map \(\phi\). If
\(\psi:\mathcal{X}\to\mathbb{Z}_N\) is a different bijection, it generally
produces a different successor map \(s_\psi\), a different conjugate
\(g_{f,\psi}\), and a different directed distance \(d_{f,\psi}\). Thus, the
MSR order is transported from the specified latent arithmetic coordinates;
it is not an intrinsic order determined by \(f\) alone.

### 2.1 Transition Matrix

For \(x,y\in\mathcal{X}\), define the matrix
\(M^{(f,\phi)}\) by

\[
M^{(f,\phi)}_{x,y}
=
\begin{cases}
1, & g_{f,\phi}(x)=y,\\
0, & \text{otherwise}.
\end{cases}
\]

Because \(g_{f,\phi}\) is a permutation, every row and every column of
\(M^{(f,\phi)}\) contains exactly one entry equal to \(1\). Therefore,
\(M^{(f,\phi)}\) is a permutation matrix.

It may also be viewed as the transition matrix of a deterministic Markov chain. In this interpretation, every transition has probability \(1\), so the probabilistic terminology adds no randomness; the underlying object is a deterministic dynamical system on a directed cycle.

## 3. Directed MSR Distance

For fixed \(f\) and \(\phi\), define the MSR directed distance

\[
d_{f,\phi}:\mathcal{X}\times\mathcal{X}
\to
\{0,1,\ldots,N-1\}
\]

by

\[
d_{f,\phi}(x,y)
=
\min\left\{
k\in\mathbb{N}_0:
g_{f,\phi}^{\,k}(x)=y
\right\}.
\]

Because \(g_{f,\phi}\) is a single cycle of length \(N\), this minimum exists
and lies uniquely in

\[
\{0,1,\ldots,N-1\}.
\]

Using the definition of \(g_{f,\phi}\),

\[
g_{f,\phi}^{\,k}
=
f\circ s_\phi^{\,k}\circ f^{-1},
\]

and therefore

\[
d_{f,\phi}(x,y)
=
\left(
\phi(f^{-1}(y))
-
\phi(f^{-1}(x))
\right)\bmod N.
\]

The notation \(d_{f,\phi}\) is retained throughout so that the dependence
on the permutation and the arithmetic coordinate map remains explicit.

For the observed states \(B=f(A)\) and \(D=f(C)\),

\[
d_{f,\phi}(B,D)
=
\left(\phi(C)-\phi(A)\right)\bmod N
=
\Delta.
\]

Hence, MSR exactly represents the latent modular displacement as a directed hitting-time distance in observation space.

### 3.1 Distance Properties

For all \(x,y,z\in\mathcal{X}\):

1. **Non-negativity**
   \[
   d_{f,\phi}(x,y)\ge 0.
   \]

2. **Identity of indiscernibles**
   \[
   d_{f,\phi}(x,y)=0
   \iff
   x=y.
   \]

3. **Triangle inequality**
   \[
   d_{f,\phi}(x,z)
   \le
   d_{f,\phi}(x,y)+d_{f,\phi}(y,z).
   \]

   To see this, let
   \(a=d_{f,\phi}(x,y)\) and
   \(b=d_{f,\phi}(y,z)\).
   Then \(g_{f,\phi}^{\,a+b}(x)=z\). The canonical forward distance from \(x\) to \(z\) is
   \((a+b)\bmod N\), which is no greater than \(a+b\).

4. **Symmetry behavior**
   For \(x\ne y\),
   \[
   d_{f,\phi}(x,y)+d_{f,\phi}(y,x)=N.
   \]

   If \(N\ge4\), the distance is not symmetric in general. An antipodal pair
   with forward distance \(N/2\) is an exception for which
   \[
   d_{f,\phi}(x,y)=d_{f,\phi}(y,x)=N/2.
   \]

   The edge case \(N=2\), equivalently \(n=1\), has only one unordered pair
   of distinct states, and that pair is antipodal. Consequently,
   \(d_{f,\phi}\) is symmetric in that exceptional two-state system.

Accordingly, \(d_{f,\phi}\) is a separating directed quasi-metric under
the convention that a quasi-metric satisfies non-negativity, identity of
indiscernibles, and the triangle inequality but need not be symmetric. It is
generally non-symmetric for \(N\ge4\), while it reduces to an ordinary metric
when \(N=2\). Terminology varies across the literature, so “directed cycle
distance” is the least ambiguous description.

## 4. Oracle Model and Recoverability

Assume that the evaluator receives \(B\) and \(D\) and has classical black-box access only to

\[
x\longmapsto f(x).
\]

The evaluator is not given the internal description, secret key, inverse circuit, or an oracle for \(f^{-1}\). This restriction is part of the computational model; bijectivity alone does not imply one-way hardness.

Although \(g_{f,\phi}\) is mathematically well-defined, its defining
formula is

\[
g_{f,\phi}(y)=f(f^{-1}(y)\oplus1).
\]

The straightforward exact evaluation method therefore first obtains
\(f^{-1}(y)\). The conjugacy identity alone does not prove that every possible
algorithm for outputting \(g_{f,\phi}(y)\) must explicitly recover or retain
that preimage, so no such stronger necessity claim is made here.

A forward oracle can reveal sampled edges of \(g_{f,\phi}\): for any chosen latent
input \(u\), the two values \(f(u)\) and \(f(u\oplus1)\) reveal the edge

\[
f(u)\longrightarrow f(u\oplus1).
\]

Because \(g_{f,\phi}\) consists of one global cycle, every such sampled edge already
lies on the same cycle as \(B\) and \(D\). The obstacle is therefore not
topological intersection. The obstacle is determining the sampled edge's
offset relative to the externally specified targets.

Sampling an edge does not provide random access to \(g_{f,\phi}\). In
particular, knowing edges generated from unrelated chosen inputs does not by
itself identify the edge leaving \(B\). Once \(A=f^{-1}(B)\) is known, that
edge is obtained by the single additional evaluation \(f(A\oplus1)\).
Accordingly, a forward oracle for \(f\) does not directly implement a
one-query random-access oracle for \(g_{f,\phi}\) at specified target states.
This statement does not assert a separate lower bound for the isolated task
of computing \(g_{f,\phi}(B)\).

There are two straightforward generic recovery strategies.

### 4.1 Recover Both Preimages

Recover

\[
A=f^{-1}(B)
\qquad\text{and}\qquad
C=f^{-1}(D),
\]

then compute

\[
\Delta
=
\bigl(\phi(C)-\phi(A)\bigr)\bmod N.
\]

A single exhaustive enumeration of the domain can search for both targets simultaneously.

### 4.2 Recover One Preimage and Traverse

Recover \(A=f^{-1}(B)\). If \(B=D\), then \(\Delta=0\) and no traversal
query is needed. Otherwise, inspect the sequence

\[
f(A\oplus1),\,
f(A\oplus2),\ldots
\]

until \(D\) is reached. The target occurs at \(f(A\oplus\Delta)\).

A naïve second phase that evaluates every term afresh makes exactly
\(\Delta\) oracle calls. This count applies only when the first phase retains
\(A\) but does not retain useful information about \(D\).

Constant auxiliary memory does **not** force this behavior. During an
exhaustive search for \(A\), the evaluator can compare every observed output
with both \(B\) and \(D\) and retain the corresponding inputs using only
\(O(1)\) machine words. If \(C=f^{-1}(D)\) is encountered, retaining it
eliminates the traversal phase entirely and reduces the procedure to the
two-preimage strategy of Section 4.1.

More generally, any previously retained value among
\(f(A\oplus1),\ldots,f(A\oplus\Delta)\) can reduce the number of **new**
oracle calls. Therefore, \(\Delta\) is the exact call count only for the
specified uncached traversal implementation, not a consequence of the memory
bound.

Including \(f(A\oplus0)=B\) as a fresh call in the second phase would be
redundant and would make that uncached count \(\Delta+1\), not \(\Delta\).

This strategy does not improve the worst-case asymptotic complexity because
\(\Delta\) may equal \(N-1\).

Neither strategy follows edges of \(g_{f,\phi}\) without latent-state knowledge. Both implement the same induced trajectory through evaluations of \(f\) at explicitly known latent inputs.

## 5. Classical Query Complexity

The following analysis uses the ideal-permutation model. For each \(n\),
first fix arbitrary distinct labels

\[
B_n,D_n\in\{0,1\}^n
\]

without using information about the permutation to be sampled. Then select
\(f_n\) uniformly from all permutations of \(\{0,1\}^n\). Within a fixed
instance, the subscripts are suppressed and the labels are written simply as
\(B,D\). Their preimages are therefore a uniformly random ordered pair of
distinct inputs. Consequently, for distinct targets,

\[
\Pr[\Delta=\delta]
=
\frac{1}{N-1},
\qquad
\delta\in\{1,\ldots,N-1\},
\]

because each nonzero displacement \(\delta\) occurs for exactly the \(N\)
ordered pairs \((a,a\oplus\delta)\). In particular, without any oracle query,
the optimal success probability for guessing \(\Delta\) is \(1/(N-1)\).

No preprocessing information correlated with the sampled permutation is
available unless explicitly stated.

These are distributional black-box query bounds over the sampled ideal
permutation. They do not claim that every fixed permutation is difficult: a
specially structured permutation, a permutation whose inverse description is
known, or a member of a succinct keyed family may be easier to invert.

For a public keyed family, key enumeration is a separate
offline-computation strategy. Under the displacement-identifiability and
efficient-inversion assumptions defined in Section 1.1, it uses \(t\)
target-oracle queries to collect \(t\) verification pairs,
\(O(t2^\kappa)\) public forward-family evaluations, and \(O(1)\) inverse
evaluations after selecting a surviving key. It should not be compared with
\(\Theta(2^n)\) ideal-permutation **query complexity** without explicitly
stating which resource—target-oracle queries, local evaluations, time, or
memory—is being measured.

### 5.1 Inverting One Fixed Target

For an integer \(q\) with \(0\le q\le N\), after \(q\) distinct forward
queries, the probability that one of the queried inputs is the preimage of a
fixed target \(B\) is

\[
\frac{q}{N}.
\]

For \(0\le q\le N-1\), if the evaluator is additionally permitted one final guess among the unqueried inputs, the total success probability is at most

\[
\frac{q+1}{N}.
\]

For \(q=N\), the target preimage has already been queried with probability \(1\).

Consequently, for any fixed constant
\(\varepsilon\in(0,1]\), independent of \(n\), achieving success probability
at least \(\varepsilon\) requires

\[
\Theta(N)=\Theta(2^n)
\]

classical forward-oracle queries. At the concrete parameter value
\(n=256\), the corresponding generic query scale is on the order of
\(2^{256}\); asymptotic notation applies to the varying-\(n\) family, not to
the single fixed instance.

For exhaustive search in a uniformly random order, the expected number of queries until the target is actually queried is

\[
\frac{N+1}{2}.
\]

If the evaluator may infer that the sole remaining unqueried input is the preimage after \(N-1\) unsuccessful queries, the expected number of oracle queries is instead

\[
\frac{N+1}{2}-\frac{1}{N}.
\]

The distinction is negligible asymptotically but is included for exactness.

### 5.2 Recovering the Directed Displacement

If \(B=D\), bijectivity implies \(A=C\), so

\[
\Delta=0
\]

is known immediately without any oracle query.

There is also a finite edge case when \(N=2\), equivalently \(n=1\). If
\(B\ne D\), then \(A\ne C\), and the only nonzero residue modulo \(2\) is
\(1\). Hence

\[
\Delta=1
\]

is also known without an oracle query.

Accordingly, the genuinely nontrivial distinct-target recovery problem begins
at \(N\ge4\), equivalently \(n\ge2\).

For \(N\ge4\) and \(B\ne D\), a simple exhaustive enumeration can record the
inputs producing \(B\) and \(D\). If the enumeration order is independent of the ideal permutation, the two preimage positions are distinct uniformly distributed positions in
\(\{1,\ldots,N\}\).

If the evaluator insists on querying both preimages, the expected stopping position is

\[
\mathbb{E}[\max(T_B,T_D)]
=
\frac{2(N+1)}{3}.
\]

Under the stopping rule that infers the second preimage when only one input
remains unqueried, the expected oracle-query count is

\[
\frac{2(N+1)}{3}-\frac{2}{N},
\]

because the maximum position equals \(N\) with probability \(2/N\), saving
one final query in precisely those cases. This is an upper bound for a simple
strategy, not a claim that no rarer transcript permits earlier inference.

The same strategy has worst-case query cost \(N-1\): after \(N-1\) distinct
queries, any designated preimage not yet observed must be the sole unqueried
input.

This gives an \(O(N)\) upper bound using \(O(1)\) machine words of auxiliary
storage, equivalently \(O(\log N)\) auxiliary bits.

A quantitative generic lower bound can also be stated. Consider any deterministic classical algorithm making at most \(q\)
distinct adaptive forward queries, with no preprocessing correlated with
\(f\). Repeated queries provide no new information and may be removed. An
algorithm that stops after fewer than \(q\) queries may be padded to exactly
\(q\) distinct queries whose answers are ignored and whose addition does not
alter the algorithm's original output. This permits analysis at a fixed query
count without increasing the padded algorithm's success probability.

By deferred decisions for a uniformly random permutation, conditional on any
transcript that has not exposed a particular designated output, that output's
preimage is uniform over the unqueried inputs. If neither \(B\) nor \(D\) has appeared, their ordered
preimage pair is uniform over all ordered pairs of distinct unqueried inputs.

Partition success according to how many of the two designated preimages occur among the \(q\) queried inputs.

1. **Both preimages queried.** This event has probability
   \[
   \frac{q(q-1)}{N(N-1)}.
   \]

2. **Exactly one preimage queried.** This event has probability
   \[
   \frac{2q(N-q)}{N(N-1)}.
   \]
   Conditional on this event, the other preimage is uniform over the \(N-q\) unqueried inputs. Since knowing one preimage makes each candidate value of \(\Delta\) correspond to exactly one candidate for the other preimage, the conditional success probability is at most \(1/(N-q)\). Hence this case contributes at most
   \[
   \frac{2q}{N(N-1)}.
   \]

3. **Neither preimage queried.** Let \(U\) be the set of unqueried inputs and let \(m=|U|=N-q\). Conditional on this event, the ordered pair \((A,C)\) is uniform over the \(m(m-1)\) ordered pairs of distinct elements of \(U\). For any fixed nonzero candidate displacement \(\delta\), the number of pairs satisfying \(C=A\oplus\delta\) is
   \[
   \left|\{a\in U:a\oplus\delta\in U\}\right|
   =
   |U\cap(U\ominus\delta)|
   \le m,
   \]
   where \(U\ominus\delta=\{u\ominus\delta:u\in U\}\). Therefore, conditional success is at most \(1/(m-1)\). Multiplying by the probability
   \[
   \frac{m(m-1)}{N(N-1)}
   \]
   of this case gives a contribution of at most
   \[
   \frac{m}{N(N-1)}
   =
   \frac{N-q}{N(N-1)}.
   \]

For \(q\le N-2\), summing the three disjoint cases yields

\[
\Pr[\widehat{\Delta}=\Delta]
\le
\frac{q(q-1)}{N(N-1)}
+
\frac{2q}{N(N-1)}
+
\frac{N-q}{N(N-1)}
=
\frac{q^2+N}{N(N-1)}.
\]

Randomized algorithms satisfy the same bound by conditioning on their
internal randomness and then averaging. Here the success probability is
averaged jointly over the uniformly sampled ideal permutation and the
algorithm's internal randomness. Therefore, for \(q\le N-2\), average success probability at least the fixed
\(\varepsilon\in(0,1]\) defined above implies

\[
q
\ge
\sqrt{\varepsilon N(N-1)-N},
\]

whenever the expression under the square root is nonnegative. If
\(q\ge N-1\), then \(q=\Omega(N)\) holds immediately. Consequently, in all
cases, constant success probability requires

\[
q=\Omega(N).
\]

Combining this lower bound with exhaustive enumeration gives, for the
nontrivial family \(n\ge2\),

\[
\Theta(N)=\Theta(2^n)
\]

classical query complexity for exact distinct-target recovery with average
success probability at least a fixed constant
\(\varepsilon\in(0,1]\) over the
uniform ideal-permutation distribution. This distributional lower bound also
applies to any algorithm required to achieve that success probability for
every permutation. At \(n=256\), this family bound evaluates to a
generic query scale on the order of \(2^{256}\).

The asymptotic statement is the central point. Exact constants depend on the search strategy, stopping rule, prior information about \(\Delta\), and whether preprocessing correlated with \(f\) is allowed.

### 5.3 Why the Birthday Bound Does Not Apply

The ordinary birthday bound concerns finding an arbitrary collision among
many samples from a non-injective range. Here, \(f\) is a permutation and
therefore has no output collisions, while the task is tied to two specified
outputs \(B\) and \(D\).

One could define other derived collision problems, but a birthday heuristic
alone would not establish recovery of the specified displacement. The
explicit lower bound in Section 5.2 rules out a generic
\(\Theta(\sqrt N)\)-query classical solution in the stated ideal-permutation
model. Thus, the ordinary birthday-collision argument is not applicable to
this recovery task.

## 6. Space and Preprocessing Trade-offs

For an arbitrary ideal permutation treated extensionally, a complete inverse
table contains one entry for each of the \(N\) outputs and requires

\[
\Theta(N)
\]

machine words, or \(\Theta(N\log N)\) bits under an explicit bit-cost
accounting.

In the classical point-query model, an exact complete table can be
constructed with \(N-1\) distinct forward queries: after querying \(N-1\)
inputs, the sole unqueried input must map to the sole unobserved output.
Conversely, fewer than \(N-1\) classical point queries leave at least two
unqueried inputs and two unobserved outputs, allowing at least two
permutation completions with different inverse tables. Hence exact full
tabulation has classical worst-case preprocessing query complexity exactly
\(N-1\).

This argument is not a quantum full-oracle-learning lower bound: a coherent
quantum query is not equivalent to selecting one classical input and leaving
all other inputs untouched. No quantum complexity claim for learning the
entire inverse table is made here.

This is a tabulation bound, not a universal representation lower bound for
structured permutation families. For example, a keyed block cipher
may have a succinct description of \(O(\kappa)\) key bits together with a
fixed public algorithm. In a word-RAM model with word length \(\Theta(\log N)=\Theta(n)\), such a
table would permit subsequent preimage lookups and displacement calculations
using \(O(1)\) table accesses and no further oracle queries.

However, \(\Theta(N)\) storage is **not** required for a one-time exhaustive recovery. A sequential search can locate both preimages while retaining only the two matching inputs and a loop counter.

Therefore:

- complete reusable tabulation requires \(\Theta(N)\) machine words, or \(\Theta(N\log N)\) bits;
- one-instance exhaustive recovery uses \(O(1)\) machine words, equivalently \(O(\log N)\) auxiliary bits;
- intermediate time-memory trade-offs may be possible, but they do not make the MSR graph representation itself an inversion shortcut.

Any claim that the problem inherently requires \(\Theta(N)\) memory would be incorrect.

## 7. Quantum Qualification

The \(\Theta(2^n)\) bound above is a statement about the varying-\(n\)
classical-query family. At the concrete value \(n=256\), it corresponds to a
generic scale on the order of \(2^{256}\) queries.

### 7.1 Required Quantum Oracle Model

The quantum bound depends critically on how oracle access is defined. Use the
standard forward function-evaluation oracle

\[
O_f:\lvert x,z\rangle
\longmapsto
\lvert x,z\oplus_{\mathrm{bit}} f(x)\rangle,
\]

where \(\oplus_{\mathrm{bit}}\) denotes bitwise XOR on the second register.
The evaluator may query \(O_f\) coherently but is not given a separate oracle
for \(f^{-1}\).

Although \(O_f\) is reversible and satisfies \(O_f^{-1}=O_f\), applying it
backward merely uncomputes a previously written value of \(f(x)\); it does
not map an arbitrary output \(y\) to \(f^{-1}(y)\).

This distinction is essential. Another forward-only model supplies the
in-place permutation oracle

\[
U_f\lvert x\rangle=\lvert f(x)\rangle
\]

but does not supply \(U_f^\dagger\). Recent work supplies an

\[
O(\sqrt N)
\]

permutation-inversion algorithm in this forward in-place model. Together with
the established \(\Omega(\sqrt N)\) in-place lower bound discussed in that
work, the query complexity is \(\Theta(\sqrt N)\). This is separate from the
\(O_f\)-oracle proof given below.

By contrast, if access to the adjoint \(U_f^\dagger\) is supplied, then

\[
U_f^\dagger\lvert y\rangle
=
\lvert f^{-1}(y)\rangle.
\]

In that strictly stronger model, arbitrary distinct targets can be handled
by applying \(U_f^\dagger\) once to \(B\) and once to \(D\), for two
inverse-unitary invocations in the ordinary sequential query count. This is
an upper bound of \(O(1)\), not a universal exact count: if \(B=D\), then
\(\Delta=0\) is known without an oracle call, and when \(N=2\) distinct
targets already force \(\Delta=1\). The two invocations could be issued in
one parallel query round if the model permits two simultaneous oracle uses,
but the total invocation count remains two in the generic distinct-target
procedure. Thus, the relevant distinction is not merely “XOR oracle versus
in-place oracle,” but whether direct inverse-permutation access is available.

### 7.2 Upper Bound

Using \(O_f\), the predicate

\[
h_B(x)=
\begin{cases}
1,& f(x)=B,\\
0,& \text{otherwise}
\end{cases}
\]

has exactly one marked input. Grover search or amplitude amplification
therefore recovers \(f^{-1}(B)\) with bounded error using

\[
O(\sqrt N)=O(2^{n/2})
\]

queries to \(O_f\). A phase-marking implementation may use one query to
compute \(f(x)\), a comparison with \(B\), and a second query to uncompute
\(f(x)\); this affects only the constant factor.

Run the search for \(B\) and for \(D\), amplifying each individual success
probability to at least \(5/6\). By the union bound, both searches then
succeed simultaneously with probability at least

\[
1-\frac16-\frac16=\frac23.
\]

The recovered values are

\[
A=f^{-1}(B)
\qquad\text{and}\qquad
C=f^{-1}(D),
\]

after which

\[
\Delta
=
\bigl(\phi(C)-\phi(A)\bigr)\bmod N
\]

is computed without further oracle queries. Constant-error amplification
changes only a constant factor, so displacement recovery has bounded-error
upper bound

\[
O(\sqrt N).
\]

### 7.3 Lower Bound

For the matching worst-case lower bound, suppose a bounded-error quantum
algorithm uses at most \(q\) queries to \(O_f\), has no advice or preprocessing
correlated with \(f\), and satisfies the following guarantee:

for every permutation \(f:\mathcal{X}\to\mathcal{X}\) and every distinct
target pair \((B,D)\), it returns the exact displacement with probability at
least \(2/3\).

The probability is over the algorithm's internal quantum measurement
outcomes.

Given a fixed-target inversion instance \((f,B)\), choose a known input
\(c_0\) and use one query to obtain

\[
D=f(c_0).
\]

If \(D=B\), then \(c_0=f^{-1}(B)\) and inversion is complete. Otherwise, run
the displacement algorithm on \((B,D)\). Its output is

\[
\Delta
=
\phi(c_0)-\phi(f^{-1}(B))
\pmod N.
\]

Therefore,

\[
f^{-1}(B)
=
c_0\ominus\Delta.
\]

A displacement algorithm using \(q\) queries would consequently yield a
fixed-target permutation inverter using \(q+1\) queries and the same bounded
error. Permutation inversion under a forward function-evaluation oracle has
quantum query complexity \(\Theta(\sqrt N)\); in particular, the lower bound
implies

\[
q=\Omega(\sqrt N).
\]

This invocation is specifically a permutation-inversion lower bound, not an
unsupported replacement of the full-value oracle \(O_f\) by an equality-only
oracle. A direct equivalence between permutation inversion and unordered
search is established by Nayak (2011).

Combining the upper and lower bounds gives

\[
\Theta(\sqrt N)=\Theta(2^{n/2})
\]

bounded-error worst-case quantum query complexity for the black-box
permutation problem, for solvers required to handle every permutation and
every distinct target pair in the stated \(O_f\) oracle model. At \(n=256\), the
corresponding generic quantum-query scale is on the order of \(2^{128}\).

This is a worst-case black-box guarantee and does not require sampling
\(f\) from a probability distribution. It is not a separately proved average-case theorem for every
possible target-generation distribution.

For a publicly specified keyed family, quantum key search also belongs to a
different resource model. Assume that:

1. a reversible circuit for coherently evaluating \(f_{K'}(x_i)\) from a
   candidate key \(K'\) is available;
2. the verification set \(S\) gives an efficiently computable marking
   predicate;
3. efficient evaluation of \(f_{K'}^{-1}\) is available after a classical
   candidate key has been measured; and
4. every marked key yields the same candidate displacement
   \(\Delta_{K'}\), although their individual preimages need not coincide.

After \(t\) target-oracle queries used to collect \(S\), one evaluation of
the key-marking predicate requires checking all \(t\) verification pairs.
A reversible implementation therefore uses \(O(t)\) coherent evaluations of
the public keyed-family circuit, including uncomputation up to a constant
factor.

If the verification predicate has exactly \(r\ge1\) marked keys and \(r\)
is known, amplitude amplification finds a marked key using

\[
O\!\left(\sqrt{\frac{2^\kappa}{r}}\right)
\]

marking-oracle invocations. If \(r\) is unknown, standard variable-iteration
quantum search gives the same order as an expected-query upper bound.
Consequently, the number of coherent keyed-family circuit evaluations in the
straightforward verification implementation is

\[
O\!\left(
t\sqrt{\frac{2^\kappa}{r}}
\right).
\]

For a unique marked key, this becomes

\[
O\!\left(t2^{\kappa/2}\right),
\]

not \(O(2^{\kappa/2})\) unless \(t=O(1)\) or the factor \(t\) is deliberately
suppressed under a separate soft-asymptotic convention.

These circuit evaluations are not queries to the instantiated oracle
\(O_{f_K}\). Measuring any marked key then suffices to compute the common
displacement when displacement identifiability is supplied as a promise. If
that agreement must be certified rather than assumed, ordinary amplitude
amplification for one marked key is insufficient; the additional cost of
determining whether all marked keys induce the same displacement must be
analyzed separately. If marked keys produce different displacements,
ordinary key search alone does not determine which candidate displacement is
the operative one.

Thus, as in the classical case, the \(\Theta(2^{n/2})\)
ideal-permutation query bound is not automatically a lower bound on the
total computational work for every succinct cryptographic family.

The quantity above counts coherent evaluations of a public keyed-family
circuit, while the ideal-permutation bound counts queries to an abstract
oracle \(O_f\). These are not intrinsically the same resource.

If one deliberately normalizes one coherent family-circuit evaluation and
one ideal-oracle query to equal unit cost, then in the unique-survivor case
the numerical operation counts satisfy

\[
t(n)2^{\kappa(n)/2}=o(2^{n/2})
\]

exactly when

\[
n-\kappa(n)-2\log_2 t(n)\longrightarrow+\infty.
\]

Without such a normalization, this is not a running-time comparison. It is
also not a necessary condition for every quantum algorithm exploiting the
keyed family. Circuit depth, gate count, workspace, error-correction cost,
parallelism, and family-specific structure may all alter the relevant
complexity.

## 9. Scope and Interpretation

MSR establishes the following exact equivalence:

\[
\boxed{
d_{f,\phi}(B,D)
=
\left(
\phi(f^{-1}(D))
-
\phi(f^{-1}(B))
\right)\bmod 2^n
}
\]

This equivalence gives a valid graph-theoretic representation of latent modular arithmetic under a cryptographic permutation. With unrestricted \(\Delta\), however, it does not impose additional structure on \((A,C)\); it assigns the unique directed modular displacement that already exists for every ordered pair.

It does not imply that:

- nearby latent inputs produce nearby observable outputs under an ordinary output-space metric;
- a forward oracle for \(f\) supplies an efficiently computable oracle for \(g_{f,\phi}\);
- sampled “shadow trajectories” form a separate cycle that must somehow
  intersect the targets' cycle; in fact, every sampled segment lies on the
  same global cycle, but its offset relative to \(B\) and \(D\) remains
  unknown unless target-linked preimage information is obtained;
- graph terminology reduces the generic cost of preimage recovery;
- observing sampled edges of the induced cycle supplies an efficient
  target-linked shortcut for computing \(d_{f,\phi}(B,D)\); sampled edges are
  observable, but without locating the specified targets in latent
  coordinates they do not calibrate the required offset.

Once both \(f\) and the latent coordinate map \(\phi\) are fixed,
\(G_{f,\phi}\) is fully determined. Local navigation from a self-generated
state \(f(u)\) is easy when \(u\) is known. For externally specified targets,
the construction supplies no direct random-access navigation rule from the
forward oracle alone. The proven hardness statement in this document concerns
recovery of the target-linked distance \(d_{f,\phi}(B,D)\), not a separately
formalized lower bound for every individual transition-evaluation task. The classical lower bound is distributional over
an ideal random permutation. The quantum lower bound is a bounded-error worst-case bound under the
standard forward function-evaluation oracle \(O_f\), without inverse-oracle
access. Forward in-place access \(U_f\) without \(U_f^\dagger\) has the same
\(\Theta(\sqrt N)\) query complexity by a separate result.

## 11. Conclusion

Markovian State Realignment is a mathematically consistent conjugacy
construction. For an \(n\)-bit state space, modular increment forms one
directed cycle of length \(2^n\), and conjugation by a permutation transfers
that cycle structure exactly to the observation space. In the target
\(n=256\) instance, the cycle length is \(2^{256}\). The unrestricted equation \(C=A\oplus\Delta\) is definitional rather than a restrictive promise: every ordered latent pair determines one and only one directed modular displacement.

For each fixed pair \((f,\phi)\), the resulting directed hitting-time
distance \(d_{f,\phi}\) is equal to the hidden modular displacement between
the unique preimages of the observed states. It is a separating directed
quasi-metric and, more unambiguously, a directed cycle
distance. It is generally non-symmetric for \(n\ge2\); for the exceptional
case \(n=1\), it is symmetric.

For distinct targets under classical forward-only access to an ideal
\(n\)-bit permutation, the \(n=1\) instance is trivial:
\(\Delta=1\). For the nontrivial family \(n\ge2\), under the uniform
ideal-permutation distribution described in Section 5, recovery of the exact
displacement with average success probability at least a fixed constant has
classical target-oracle query complexity \(\Theta(2^n)\) as \(n\) varies.
The same lower bound applies a fortiori to solvers required to meet that
success probability for every permutation.

This conclusion must not be silently transferred to a public keyed family.
When displacement identifiability is supplied as a promise and efficient
inversion is available after key recovery, a worst-case exhaustive search for
one survivor uses only \(t\) queries to the instantiated target oracle but at
most \(O(t2^\kappa)\) offline evaluations of the public keyed family.
Certifying the promise may require completing a scan of all \(2^\kappa\)
candidate keys, plus inverse evaluations for the surviving keys; its cost is
not generally proportional only to the number of survivors. A unique key is
sufficient but not necessary; multiple surviving keys are harmless when they
all induce the same \(\Delta\).
Family-specific cryptanalysis may reduce the computational work further.
These quantities measure different resources and are not interchangeable. A one-time exhaustive search needs only
\(O(1)\) machine words, equivalently \(O(n)\) auxiliary bits. The degenerate
case \(B=D\) yields \(\Delta=0\) immediately. For an extensionally represented ideal permutation, full reusable inverse
tabulation requires exactly \(2^n-1\) forward preprocessing queries in the
classical point-query model, together with \(\Theta(2^n)\) stored words,
equivalently \(\Theta(n2^n)\) bits. No claim about the quantum query
complexity of learning the entire table is included.

Under coherent access to the standard forward function-evaluation oracle
\(O_f\), without inverse-permutation access, bounded-error worst-case query complexity for the black-box permutation
problem is \(\Theta(2^{n/2})\). Forward in-place
access \(U_f\) without \(U_f^\dagger\) has the same asymptotic query
complexity. If \(U_f^\dagger\) is supplied, two inverse-unitary calls suffice for the
generic distinct-target procedure, while the trivial cases \(B=D\) and
\(N=2\) require none.

For a public keyed-family sequence with key length \(\kappa(n)\)
satisfying the stated displacement-identifiability,
reversible-forward-evaluation, and efficient-inversion conditions, quantum
key search may instead use \(t(n)\) target-oracle queries to collect
verification data. Within a particular instance, write \(t=t(n)\) and
\(\kappa=\kappa(n)\). If \(r\) keys survive the verification set, finding
one of them uses

\[
O\!\left(
t\sqrt{\frac{2^\kappa}{r}}
\right)
\]

coherent evaluations of the public family circuit. In the unique-key case
this is \(O(t2^{\kappa/2})\). This is a keyed-family circuit-evaluation count, not an
ideal-permutation oracle-query count. Converting either quantity into running
time requires an explicit implementation and cost model.

For the concrete target value \(n=256\), the family bounds correspond to
generic scales on the order of \(2^{256}\) classical queries,
\(2^{256}\) stored words for complete tabulation, and \(2^{128}\)
bounded-error quantum queries.

Accordingly, MSR is a rigorous formal reframing of the latent relation, not a cryptanalytic speedup.
