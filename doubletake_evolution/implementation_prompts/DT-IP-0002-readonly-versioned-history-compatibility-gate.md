## Conditional minimal behavior

Where a real existing verification seam and documented version-drift defect are demonstrated, test a **read-only** version-bound replay discriminator: bind immutable input-history digest, event/command ordering, recorded external-effect outcomes, interpreter/schema version, and resulting command sequence; compare replayed decisions against recorded evidence without executing activities, network calls, LLM calls, clock/random branches, or other effects. Model nondeterminism using recorded outcomes or fail closed. Explicitly separate legitimate version/representation compatibility (authorized mapping with provenance) from corrupt, forged, unsigned, mismatched or ambiguous evidence. Never rehash/reseal/alter originals, bypass signature or integrity checks, change production state, grant new authority, add a parallel verifier, or turn a compatibility classification into an owner disposition.

Existing DT verifier and history owner are hypotheses, not confirmed interfaces. Keep native implementation minimal; benchmark cost/storage/privacy and reject additional infrastructure unless justified. Existing protected-history no-loss, authorization and integrity stops remain mandatory.

## Falsifiable acceptance fixtures and gates

Use synthetic/public-safe histories only: at least **10** old-version compatible records, **10** explicitly authorized changed-representation records, and **10** intentionally tampered/mismatched records. Include positive same-version replay, authorized version migration with matching command/effect receipts, and negative incompatible branch/command divergence, forged digest/signature, unknown interpreter version, missing provenance, clock/random nondeterminism, mismatched effect receipts, unauthorized representation alias, and attempted duplicate external effect. Explicitly label which variants are approved; never silently normalize mismatches.

Measure current baseline versus candidate for true acceptance/rejection, false accept/reject, zero side-effect replay, runtime and owner interventions. Require **100% rejection** of deliberately tampered histories, no production writes, no repeated external effects, and fail-closed ambiguous provenance. Evaluate at least **five held-out newly constructed** fixtures; include a rejected candidate negative control. Report denominators and exact commands/results. Compatibility replay alone does not establish cryptographic authenticity or live-history safety.
