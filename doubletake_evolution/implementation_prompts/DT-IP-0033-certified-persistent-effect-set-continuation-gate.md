## Distinct, testable proposed behavior
At an **existing authorized persistent-effect evaluation and continuation seam**, require an owner-approved, immutable, occurrence/revision-bound multiset **A** of intended persistent effects, independently observed actual persistent effect multiset **E**, and a certified coverage/attribution boundary at a specified comparison granularity. Only complete attributable **E = A** yields `EXACT` and permits dependent continuation. Complete observed mismatch yields `DIVERGED`; incomplete observation, missing registered outlet, or ambiguous actor/effect attribution yields `INDETERMINATE` and **never** success. Compare multiplicities: extra, missing and duplicate effects count even when tool response is successful. Approval, observer record, operation identity, public mission SHA and continuation must bind to the same execution occurrence and revision; reject stale/replayed approval. An unregistered reachable persistence outlet invalidates any claim of complete observation. A remote issue-field readback covers only registered fields and does not causally attribute out-of-band edits.
