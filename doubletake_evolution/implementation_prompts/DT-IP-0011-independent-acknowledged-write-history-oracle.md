## Distinct conditional value
B4 / historical 3.5.2 concerns **no loss of acknowledged shared-state writes**. The source reports an existing isolated counterexample in which two writes were acknowledged but one was lost despite a valid persisted snapshot digest. The **only distinct proposed transfer** is an **independently specified, contract-faithful oracle** that can reproduce and falsify a future *claimed repair* independently of the existing 3.5.2 test. Do not build a second writer, duplicate the existing counterexample as a supposed improvement, replace the canonical owner, or treat a passing toy checker as repair evidence.

**Contract prerequisite:** the current authorized state owner must define acknowledgement point, accepted/refused operations, durability and quiescence/restart boundaries, permitted ordering and whether the promised contract is linearizability or only preservation of an accepted set. Linearizability is potentially *stronger* than DT's actual promise; a Porcupine failure under an unpromised stronger model is **not** a DT defect. Partitioning independent histories via P-compositionality is valid only if no cross-object/shared-snapshot invariant couples them. Elle's append-list semantics cannot be applied to snapshot replacement by relabeling operations. Without owner contract, baseline parity and an authorized disposable fixture, verdict **DEFER_CONTRACT_UNAVAILABLE**.
