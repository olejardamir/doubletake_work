## Test contract (isolated, reversible, precommitted)
1. **OUTWARD:** before results, freeze exact DT revision, source URL/version and K hash, permission/owner decision, target capability, held-out task manifest, matched baseline, positive/negative expected outcomes, evaluator, allowed runtime configuration and repetition plan. A synthetic K/fixture may validate harness only (**FIXTURE_ONLY**), never knowledge assimilation Ground.
2. **INWARD A:** existing DT without newly adopted K (baseline). **B:** same tasks/path with owner-approved K and trustworthy exact-revision consumption receipt. **C:** reversibly withhold K in an isolated context only (no canonical knowledge/history deletion). **D:** substitute irrelevant or wrong-entity evidence, clearly test-only; must not trigger false promotion or incorrect decisions. **E:** metamorphic controls: reorder irrelevant details, duplicate evidence ID, or paraphrase semantically equivalent tasks *after independent equivalence check*; invariant decisions and authorization must hold.
3. Keep tasks, evaluator and runtime configuration identical across A–E except the specified intervention. Control caching, stochasticity, leakage, evaluator contamination and other concurrent changes. If nondeterministic, use predeclared matched repetitions; report all outcomes, uncertainty, costs, regressions and denied effects; no arbitrary success threshold or post-hoc cherry-picking.
4. **GROUND levels (distinct, do not collapse):** (1) source/mission published; (2) exact revision actually consumed via existing trusted observer; (3) existing owner authorized and executed; (4) B independently outperforms A/C on preregistered K-dependent held-out tasks while D/E hold, replicated; (5) ordinary later authorized task reuses capability without manual answer injection. A commit, source citation, synthetic change or isolated fixture pass alone does not establish level 4/5.
5. **Negative/failure gates:** baseline already passes → ALREADY_PRESENT; B indistinguishable from A/C → NO_OBSERVED_K_EFFECT; D causes promotion or wrong decision → FAIL_WRONG_SOURCE; E changes invariant behavior → FAIL_METAMORPHIC; no trusted consumer observation → EXECUTION_RECEIPT_UNVERIFIED; no qualified K → NO_QUALIFIED_SOURCE; fixture only → FIXTURE_ONLY; missing owner/permission → BLOCKED/UNKNOWN. Regression requires owner-governed rollback, not silent promotion. Preserve protected history and production host; never widen permissions to obtain a test result.
