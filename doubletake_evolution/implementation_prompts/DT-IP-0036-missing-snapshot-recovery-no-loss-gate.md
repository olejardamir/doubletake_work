If `None`, its alternate branch warns of possible data loss, clears `context.memory` and reconstructs only `target_step.action_outputs`, then truncates history; `Memory.clear` clears working memory and change history. The step snapshot field is optional, but ordinary `RunContext.add_step` normally supplies one.
