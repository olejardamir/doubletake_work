## Distinct bounded hypothesis
Public mission 7.9.1 already calls for **static** redirected-proof-artifact negatives. A pathname checked for containment at check time can change before use time. Test deterministic check/open interleavings, including **intermediate path components**, instead of merely repeating static symlink tests. `O_NOFOLLOW` protects only the last component; `RESOLVE_NO_SYMLINKS` can restrict all components; `RESOLVE_BENEATH` and `RESOLVE_NO_MAGICLINKS` are relevant descriptor-relative restrictions. An opened descriptor remains attached to its file after pathname changes. `openat2` may yield `EAGAIN` when safe resolution cannot be established during a race. `mkstemp` exclusive creation does not make a separately checked arbitrary destination safe. These mechanisms are **options to evaluate**, not mandatory DT implementation choices. Linux-only semantics, Python bindings, symlink allowances, mount/bind-mount behavior and filesystem differences require explicit review. Public code-search nonmatch does not prove DT lacks the test.
